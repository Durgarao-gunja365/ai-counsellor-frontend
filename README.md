# AI Counsellor – Frontend

This is the **frontend** of the AI Counsellor platform built with **React**.  
It provides a guided UI for students to build their profile, discover universities, shortlist & lock choices, and track application progress.

---

## 🚀 Tech Stack

- React (Vite)
- React Router
- Axios
- Tailwind CSS
- JWT-based Authentication

---

## ✨ Features

- User authentication (login / signup)
- Guided onboarding flow
- University discovery & shortlisting
- Lock final university decision
- AI Counsellor insights panel
- Task tracking dashboard
- Responsive UI
